## Saturation and communication

No transmitted scalar exceeded the global adaptive range. This follows from how the range is constructed and does not provide independent evidence of robustness.

The implemented quantizer grid contains `2^p+1` levels. A fixed-length code therefore requires `p+1` bits per scalar. For `n=40`, each full matrix-plus-vector message contains 1640 scalars:

| p | Fixed-length bits/scalar | Payload/message, excluding ranges |
|---:|---:|---:|
| 23 | 24 | 39,360 bits |
| 25 | 26 | 42,640 bits |

The circular graph has 40 external directed arcs. Payload figures exclude the metadata or coordination needed to provide the two global adaptive ranges to receivers.

For the regenerated sweep, the minimum nominal eigenvalue was `4.1149e-10`, giving `rhs=2.0574e-10`, and the maximum matrix range was `29.581`. The resulting `lhs` decreases from `1.1284e-3` at `p=20` to `1.7631e-5` at `p=26`; hence the sufficient invertibility inequality is not satisfied by any tested case. This does not contradict the finite numerical solves, because the inequality is conservative and the implementation activates the separate diagonal safeguard.
